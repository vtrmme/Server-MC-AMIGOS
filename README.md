# Bot de Discord - Monitoreo de Minecraft & Bienvenida

Bot listo para subirse a GitHub y desplegarse en Render.com.

## Archivos del Proyecto

- `index.js`: Código fuente principal del bot.
- `package.json`: Configuración de dependencias y scripts para Render (`npm start`).
- `.gitignore`: Evita que tus credenciales (.env) se suban a GitHub.
- `.env.example`: Plantilla con las variables necesarias para configurar en Render.
